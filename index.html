CuTe layout algebra

See how shape and stride become memory.

A CuTe layout is a map from logical coordinates to physical offsets. Change the shape or stride and watch the colors tell you which elements are close in memory. The later sections turn that picture into the algorithms behind coalesce, greatest common domain, and COPY.

01 · General concept

A layout is a map from coordinates to offsets.

The grid below is logical: row i, column j. The color and the number inside each cell are the physical offset i·d₀ + j·d₁. Hover a cell to see which memory position it shares with another coordinate.

02 · Algorithm

Coalesce merges modes without changing the map.

Two adjacent modes can merge when their offsets form one contiguous run. The result has fewer modes, but evaluates to exactly the same physical offsets. Colors mark the merge groups.

Layout inputs

Flat modes only. CuTe merges adjacent modes in order: (2,3):(3,1) is contiguous in memory but not coalesced.

03 · Algorithm

Greatest common domain finds the aligned common shape.

The result depends only on the shapes. Its returned strides are the offsets where those shared factors align. Try changing the order of A's modes: the tensor is unchanged up to an index swap, but the common domain can become much larger.

Shape inputs

Factors are processed in order. A different mode order is a different walk, even when the total size is unchanged.

04 · Algorithm pipeline

COPY turns one loop into four layout stages.

Pick a source/destination pair and step through the pipeline. The colored cells are logical indices: matching colors mean the same element. The stages reshape the domain, remove duplicate writes, and align the loop to destination memory order before looking for a contiguous vector.
