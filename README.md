# CuTe Layout Lab

An interactive, dependency-free web page for building intuition about CuTe
layouts and the algorithms used by COPY.

The page starts with the basic shape/stride picture, then walks through:

- `coalesce`
- `greatest_common_domain`
- the staged COPY pipeline: common domain, nullspace, alignment, and vector
  selection

Open `index.html` directly, or serve the directory with any static web server.

## GitHub Pages

The site is designed to publish from the repository root. Enable Pages with
the `main` branch and `/` as the source, or use a Pages deployment workflow.
